# CarPro — GR86 SIM v3 (Full Physics)

> 토요타 GR86을 기반으로 한 **웹 브라우저 레이싱 시뮬레이터**
> 외부 라이브러리 없이 순수 HTML/CSS/JavaScript 단일 파일로 구현한 풀 피직스 주행 시뮬레이션

![Track Map](map.png)

## 소개

CarPro(GR86 SIM v3)는 **인제 스피디움** 서킷에서 토요타 GR86을 주행하는 2D 탑다운 레이싱 시뮬레이터입니다.
게임 엔진이나 프레임워크 없이 Canvas 2D와 Web Audio API만으로 다음을 구현했습니다.

- **Pacejka Magic Formula 타이어 모델** (복합 슬립, 하중 민감도, 온도/마모 모델링)
- **GR86 FA24 엔진 토크 커브** 재현 (최대 토크 250 Nm @ 3700 RPM, 4000 RPM 토크 딥 포함)
- **6단 수동 변속기** + 클러치, 실차 기어비/종감속비(4.1)
- **브레이크 페이드** (온도 의존 제동력 저하, 동적 전후 브레이크 배분)
- **운전 보조 시스템**: ABS / TC(4단계) / ESC (요레이트 피드백 기반 개별 휠 제동)
- **랩 타이머**: 스타트/피니시 라인 감지, 베스트/라스트/현재 랩, 델타 표시
- **실시간 텔레메트리 HUD**: 속도, 기어, RPM 타코미터, G-포스 미터, 슬립각, 타이어/브레이크 온도, 미니맵
- **절차적 사운드 합성**: 4기통 엔진음, 타이어 스킬음, 풍절음 (녹음 파일 없이 오실레이터로 생성)
- **비주얼 이펙트**: 스키드 마크, 타이어 스모크, 브레이크등, 카메라 룩어헤드

## 실행 방법

빌드 과정이 필요 없습니다. 로컬 서버로 여는 것을 권장합니다 (트랙 마스크 이미지 처리 시 CORS 제약 때문).

```bash
cd carpro
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/main.html 접속
```

> 오디오는 브라우저 정책상 첫 키 입력 후 활성화됩니다.

## 조작법

| 키 | 기능 |
|---|---|
| `W` / `S` | 가속 / 브레이크 |
| `A` / `D` | 조향 |
| `Space` | 핸드브레이크 |
| `[` / `]` | 기어 다운 / 업 |
| `1` / `2` / `3` | ABS / TC / ESC 토글 |
| `4` | TC 레벨 변경 (off → mild → med → strict) |
| `L` | 랩 타이머 HUD 토글 |
| `C` | 스키드 마크 지우기 |
| `R` | 스타트 지점으로 리셋 |
| `H` | 도움말 표시 |

하단 대시보드 슬라이더로 **타이어 마찰계수(μ)**, **최대 조향각**, **볼륨**을 실시간 조절할 수 있습니다.

## 물리 엔진 하이라이트

| 항목 | 구현 내용 |
|---|---|
| 타이어 | Pacejka MF — 슬립비 + 슬립각 복합 슬립, 하중 1.5배 증가 시 그립 약 7~8% 감소 |
| 타이어 온도 | 최적 작동 온도 85°C, 저온은 완만한 그립 손실 / 과열은 급격한 손실 (비대칭 모델) |
| 타이어 마모 | 주행 거리에 따른 그립 저하 반영 |
| 브레이크 | 500~700°C 구간 소프트 니(knee) 이후 급격한 페이드, 하중 이동 추종 배분 |
| 차량 동역학 | 전후 중량 배분 53:47, 관성 모멘트, 에어로(양력/항력) 반영 |
| 시뮬레이션 | 60 FPS 목표, 프레임당 8 서브스텝 물리 적분 |

## 기술 스택

- **HTML5 / CSS3 / Vanilla JavaScript (ES6+)** — 프레임워크, 빌드 도구, 외부 의존성 없음
- **Canvas 2D API** — 트랙, 스키드 마크, 스모크 렌더링
- **Web Audio API** — 절차적 엔진/타이어/바람 사운드 합성
- **CSS Grid / Flexbox** — 글래스모피즘 HUD UI
